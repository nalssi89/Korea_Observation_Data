# ONI 해석 보정용 기후인자 표

- ONI를 먼저 적용하고, 아래 인자는 결론의 강도와 유사해 우선순위를 보정합니다.
- RONI는 이 보정표의 가중치에 넣지 않습니다.

## 현재 감시 인자

| 인자 | 현재 요약 | 사용 목적 | ONI 해석에서의 역할 |
| --- | --- | --- | --- |
| AO | 1월 -2.05, 2월 -1.26, 3월 +2.04 | 겨울~봄 고위도 순환 배경. 음/양 전환이 큰 해는 여름 유사해 판단에서 별도 표시. | ONI 결론을 직접 대체하지 않고 유사해 우선순위를 보정 |
| NAO | 기존 요약자료에서 자동 추출 실패 | 북대서양-유라시아 파동 배경. AO와 함께 고위도 순환의 보조 신호로 사용. | AO와 같은 방향이면 보정 신뢰도 상승, 다르면 보수적으로 해석 |
| 북극·바렌츠·카라 해빙 | 기존 요약자료에서 자동 추출 실패 | 봄철 고위도 열적 배경. 북극 전체와 바렌츠/카라를 분리해서 본다. | 저해빙 유사해가 고온·소우/다우로 갈라지면 단정 금지 |
| 유라시아 눈덮임 | 3월 22.69 백만 km2, 14주차 17.64 백만 km2 | 봄철 대륙 가열과 제트/순환장의 간접 보조 인자. | 원시 시계열이 없는 경우 기존 요약값만 쓰고 낮은 가중치 적용 |
